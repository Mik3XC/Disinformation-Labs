# Disinformation Labs™ 1.6.0

FOIA Mockup Studio adds a document layout for original fictional archive packets, with matching live preview and PDF export.

## New in this release

- **Workshop → New FOIA mockup** creates a draft with its own records-office metadata, record date, mock release date, and simulated withholding label.
- Optional archive cover sheets, repeated simulated release stamps, `SIM-` record IDs, page numbering, and a fixed fictional watermark.
- Typewriter, fax, and photocopy treatments with adjustable scan wear and black redaction bars.
- Redacted body words are replaced before PDF layout, so the original words are absent from the exported text layer. Metadata remains visible, and editable drafts and backups retain the original text.
- PDF and plain-text exports identify the document as a fictional mockup. Every PDF page carries fixed provenance labels.
- Existing workspace archives remain compatible; layout and metadata persist with each draft.
- Updated README and user guide.

## Install and run

Download `Disinformation-Labs-v1.6.0-macOS-arm64.zip`, extract **Disinformation Labs.app**, and open it. Requires **Apple Silicon and macOS 14 or newer**. Quit an older running copy before opening the updated app.

The bundle is ad-hoc signed and is **not Apple-notarized**. macOS may require review in System Settings → Privacy & Security. Intel binaries are not included.

Verify the ZIP with the accompanying checksum file:

```sh
shasum -a 256 -c SHA256SUMS.txt
```

The bundle identifier and Application Support directory are unchanged, preserving existing workspace data.

## Example and limits

The attached `fictional-foia-mockup.pdf` demonstrates the cover sheet, record pages, simulated release stamps, and black bars using original fictional text. Source FOIA documents are not bundled.

This recreates a general archive-document appearance; it does not import or reproduce arbitrary PDF layouts, handwriting, tables, diagrams, or official seals. All exports remain clearly identified as fictional mockups.
