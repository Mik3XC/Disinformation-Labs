# Disinformation Labs™ 1.5.1

First GitHub release under `Rali0s/Disinformation-Labs`.

## Included

- Blue alien branding in the sidebar and macOS app icon, with the Disinformation Labs display name.
- Richard Doty / MJ-12 dossier archive and labeled fictional memorandum studio.
- Nine country-specific English news editions with cached city and radius filtering.
- Configurable headline similarity, evidence review, and multi-city study boards.
- Offline regional coverage maps and manual tone/format annotations.
- Publication projects with manual site analytics, confirmed linked mentions, and a documented-source sprawl index.
- Local persistence, archive import/export, and PDF/text reports.
- README, detailed user guide, dataset attribution, and repeatable release packaging.

## Download

`Disinformation-Labs-v1.5.1-macOS-arm64.zip` contains **Disinformation Labs.app** for Apple Silicon running macOS 14 or newer. Verify it against the accompanying `SHA256SUMS.txt`.

The bundle is ad-hoc signed, not notarized. Intel binaries are not included. Source builds use the architecture of the build Mac.

## Validation

- 261 deterministic core/model checks.
- 88 native PDF and persistence checks, also run against the packaged executable.
- Release compilation and strict code-signature verification.

## Limits

Analytics and mentions are manual records; no live provider integrations or web monitoring are included. Similarity is lexical, geographic matches need review, and maps represent the recorded sample rather than audience reach or sentiment. The release retains the earlier bundle identifier and Application Support directory so existing workspace data continues to load.
